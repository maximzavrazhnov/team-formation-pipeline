# Team Formation Pipeline — описание на русском

Исследовательский прототип для **формирования проектных команд по цифровым следам** с использованием ограниченного поиска коалиций и кооперативно-игровой логики распределения.

Публичная версия репозитория предназначена для портфолио и воспроизводимой демонстрации. В неё входят только синтетические демонстрационные данные.

## Что делает программа

- агрегирует Jira-подобные данные по исполнителям;
- рассчитывает интегральный `S_score`;
- моделирует синтетические стоимостные параметры для demo-режима;
- ищет допустимые команды с ограничениями по бюджету и размеру;
- оценивает ценность коалиций с учётом координационных издержек;
- формирует минимальную, оптимальную и максимальную конфигурации;
- выполняет Shapley-inspired распределение бюджета;
- проводит Monte Carlo сравнение вариантов калибровки;
- сохраняет CSV/JSON результаты и графики.

## Быстрый запуск

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python scripts/run_demo.py --clean
```

На macOS/Linux вместо второй команды:

```bash
source .venv/bin/activate
```

Результаты появятся в `outputs/demo/`.

## Важное ограничение

Это исследовательский прототип, а не production HR-система. Публичный demo не содержит реальных данных сотрудников. Текущая процедура распределения является приближённой Shapley-inspired схемой на основе предельных вкладов, а эвристический поиск коалиций не гарантирует глобальный оптимум.

Подробности: [`docs/METHODOLOGY.md`](docs/METHODOLOGY.md).
